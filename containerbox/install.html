安装

装 ContainerBox 本体

1. 必须在 Safari 打开本页（微信里点「···」→ 在浏览器打开）
2. 点「安装」→ 回桌面等装完
3. 打不开时：设置 → 通用 → VPN与设备管理 → 信任证书；或 隐私与安全性 → 开发者模式 → 开启
4. 「Unable to Verify」→ 关 VPN 或换蜂窝网络再点图标

用 ContainerBox 多开微信

5. 先准备一个已解密的微信 IPA（App Store 原版带加密，装进去会闪退）—— 点这里下载 ›
6. 打开 ContainerBox → Apps → 右上「+」导入微信 IPA
7. 想多开：给微信新建多个容器（每个容器 = 一份独立数据 = 一个登录）
8. iOS 26 以下建议开 JIT（配合 SideStore/StikJIT）或在设置里导入签名证书，否则子 App 可能签名失败
