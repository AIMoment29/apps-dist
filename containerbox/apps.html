怎么用

1. 点上面「下载」→ ipa 存到「文件」App（用 Wi-Fi，约 368MB）
2. 打开 ContainerBox → Apps → 右上「+」 → 从「文件」选刚下的 ipa 导入
3. 想多开：给它新建多个容器（每个容器 = 一份独立数据 = 一个登录）
也可在 ContainerBox「从 URL 添加」里粘贴上面的下载链接，直接在手机上下。

iOS 26 必看：先设置 JIT-less

iOS 26 上导入 App 后启动会报 “JITLess mode is required”，这是 iOS 26 的限制，必须先在 ContainerBox 里导入一张签名证书（它用来在手机上给 App 签名）。一台设备只需设置一次。

证书 .p12 和密码都存在 1Password 里（签名私钥不放公开页面，找管理员要该条目的访问权）。

1. 手机装 1Password App 并登录 → 打开那条证书条目
2. 把条目里附带的 .p12 文件存到「文件」App：点附件 → 分享 → 存储到文件（密码就在同一条目里，复制备用）
3. ContainerBox → 设置 → Import Certificate → 从「文件」选这个 .p12 → 粘贴 1Password 里的密码
4. 成功后回去重开 App 即可。iOS 26 以下（如 iPhone 11）可跳过这步
导入后若仍起不来：设置里的 JITLess Diagnose 页看哪项异常。
